# Moonshot

Launch your finances to new heights.

- Ruby version `3.3.0`

- Rails `7.1.3`

## Local Development Setup

Clone this repo by running `git clone git@github.com:snehithlal/moonshot.git`.

Make sure that [yarn](https://yarnpkg.com) is installed with it as well.

Use the following commands to set up and start the application.

To setup the application.

```bash
./bin/setup
```

To start the application,

```bash
bin/dev
```

Visit http://localhost:3000
